# Meridion species registry

`records.json` is the complete creator-approved catalog of 386 profiles, accepted
on November 27, 2026. The imported JSON is byte-for-byte identical to the supplied
“Meridion Species Records - Complete Power Profiles.json”; `manifest.json`
records its checksum. The reference HTML is preserved under
`docs/species/source-registry.html` and is not executed by the game.

Original status, review, and reference-verification wording remains intact as
source provenance. The creator's acceptance applies to the entire catalog.

The registry includes biological species, ancestry, fauna, practices, and
statuses. Practices and statuses are not biological species. A catalog entry is
not a grant of all listed powers, rare traits, institutional roles, or privileges.
Existing citizens are not rewritten or automatically given these abilities.

The Royal Archive & Library and AURA share the typed registry in `registry.ts`.

`identityIndex.json` is a derived index of IDs, names, categories, and families
for personal-profile validation. A consistency test checks it against the full
catalog, which loads when the registry or character editor is opened.
